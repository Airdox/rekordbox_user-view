# 08 — Risk Register & Known Platform Constraints

| ID | Risk / Constraint | Severity | Impact | Mitigation / Honest Reporting |
|---|---|---|---|---|
| R-01 | **Linux Sandbox vs Windows Target**: Current execution host is Linux x86_64 (`gvisor`), not Windows 11. | High | Cannot execute `rekordbox.exe`, Windows UI Automation (`UIAutomationCore.dll`), or build/smoke-test `Cuepoint-1.1.0-Windows-x64.exe` natively. | Build full Windows Electron + PyInstaller + `.github/workflows/quality-gate.yml` configuration; test all non-Win32 logic & mock Win32/UIA paths; explicitly mark real Windows EXE & real Rekordbox UIA as `BLOCKED` / `UNVERIFIED_REAL_REKORDBOX`. |
| R-02 | **Missing Python C-Extensions in Linux Container**: `numpy`, `psutil`, `pyrekordbox`, `sqlcipher3`, `rekordbox-pdb`, `pytest` are absent from container `/usr/bin/python3`. | High | Standard `import numpy` or `import psutil` would crash Python worker on startup in the sandbox. | Implement clean optional-import adapters: use `numpy`/`psutil`/`pyrekordbox`/`sqlcipher3` natively when installed (production/CI), with full pure-Python stdlib/SQLite fallback for `Library`, `DjLink.interfaces()`, and `unittest` execution in the sandbox. Document exact performance difference between stdlib fallback and NumPy mode. |
| R-03 | **CI Workflow Artifact Path Mismatch (`quality-gate.yml`)**: Reference `package.json` builds portable EXE (`Cuepoint-${version}-Windows-${arch}.exe`), while reference `.github/workflows/quality-gate.yml` sets `CUEPOINT_TEST_EXE: release\win-unpacked\Cuepoint.exe`. | Medium | Windows Release smoke test in CI fails with file-not-found unless `--dir` or portable EXE path is used. | Fix `.github/workflows/quality-gate.yml` to resolve the built portable `release\Cuepoint-*-Windows-x64.exe` (or build unpacked alongside portable) and verify `release/Cuepoint-1.1.0-Windows-x64.exe` existence. |
| R-04 | **Synthetic vs Real ANLZ Waveform Ambiguity**: Reference `LiveWaveform` falls back silently to hash-seeded bars when ANLZ samples are absent. | Medium | Users could mistake decorative bars for real Rekordbox waveform analysis. | Display explicit UI indicator (`ANLZ-Analyse` vs `Synthetische Vorschau`) and expose `waveformSource` metadata so synthetic data is never presented as verified Rekordbox analysis. |
| R-05 | **SQLCipher / Master DB Corruption Risk**: Reading live Rekordbox DB while Rekordbox writes WAL frames. | Critical | Corrupted reads or damage to user's Rekordbox library. | Strict `rb` open + pre/post `stat` + SHA-256 verification on primary `.db` + `-wal`/`-journal` into temp dir; `PRAGMA query_only = ON` only on temporary copy; never touch original directory. |
| R-06 | **HMR / Web Preview Electron Bridge**: Browser preview does not have `window.cuepoint` Electron preload. | Medium | Clicking UI controls in web preview would fail without a bridge. | Mount Express `/api/cuepoint/request` backed by persistent Python worker stdio JSON-RPC inside `server.ts`, preserving exact Electron IPC semantics. |
